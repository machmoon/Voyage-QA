# Voyage QA Media

Screenshots, demo videos, and gallery assets for [Voyage](https://github.com/machmoon/Voyage).

UI tests still write fresh captures to `QA/` in the main app repo locally; committed reference shots live here to keep the code repository lean.

## Layout

- Root `*.png` — screenshot tour and onboarding captures
- `qa-*.png` — primary App Store / README tour
- `demo/` — study-trip demo videos and frame grabs
- `gallery/` — marketing gallery stills
